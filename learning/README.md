# 双臂协作项目学习手册

这个目录不是项目功能说明，而是你需要真正掌握的知识地图。目标不是“看懂代码”，而是做到：能从物理约定推导公式、能独立写出核心函数、能根据日志定位问题、能在面试中解释设计取舍。

## 1. 掌握等级

每个知识点按四个等级验收：

| 等级 | 要求 | 判断方法 |
|---|---|---|
| L1 理解 | 能用自己的话解释概念和输入输出 | 不看文档讲 2 分钟 |
| L2 推导 | 能从坐标系和物理定律推到公式 | 白板推导，不背结论 |
| L3 手写 | 能在 20–40 分钟内写出核心代码 | 关闭原实现，完成练习 |
| L4 调试 | 能设计测试、读日志并定位故障 | 注入符号/单位/参数错误 |

标有 **【必须手写】** 的内容至少达到 L3；其余核心内容至少达到 L2。面试中最危险的状态是能描述模块名称，却无法说明矩阵维度、参考点、符号或失败条件。

## 3. 最终能力清单

完成学习后，你应当能在没有项目代码提示的情况下完成以下任务：

- 明确世界系、基座系、末端系、物体系和抓取点参考系之间的变换。
- 写出 `skew()`、SE(3) 位姿复合、旋转误差和 wrench/twist 点变换。
- 推导并写出单臂 Cartesian impedance：`wrench -> J^T wrench + bias`。
- 推导 `G_i`、整体 `G`、`J_a`、`J_r`，解释为什么静力学与运动学互为对偶。
- 用加权伪逆分配物体 wrench，并证明内力项位于 `null(G)`。
- 解释刚性闭链为什么有 6 维内力空间，螺旋副为什么降为 5 维。
- 写出物体空间阻抗、负载分配、内力反馈和双臂关节力矩映射。
- 从机械臂动力学构造包含闭链、关节、力矩和碰撞约束的 QP。
- 解释为什么 QP 不能替代路径规划，以及 governor 与 safety layer 的职责边界。
- 解释轴向预紧、螺旋运动、拧紧力矩和装配状态机。
- 说明标定误差如何经过刚性闭链转化为内力，并提出实机处理流程。
- 写出 1 kHz 控制循环并保证无动态内存分配、无阻塞 I/O、输出有界。
- 设计单元测试、有限差分测试、消融实验、鲁棒性 sweep 和任务验收指标。
- 准确说明仿真结论能证明什么、不能证明什么。

## 5. 每次学习的固定流程

1. 先关闭源码，只看本章的输入、输出、维度和物理定义。
2. 在纸上推导公式，并检查单位、符号和参考点。
3. 在临时分支独立实现对应函数。
4. 运行本章给出的最小测试。
5. 与正式实现比较，但不要逐行背代码。
6. 故意制造一个错误，观察哪个测试或指标会先失败。
7. 用三句话记录：问题、根因、验证证据。

建议每个专题建立自己的学习分支：

```bash
cd /home/tt/dual_arm_ws
git switch -c learning/<topic>
```

练习结束后不要合并对正式实现的破坏性改动。需要放弃学习分支时先确认其中没有要保留的笔记或代码。
